# 交互设计经验

- 地球全景优先显示国家区块和国界；省／州边界应随放大逐级显现。点击国家先聚焦、放大并展示省州，避免在默认视角铺满全球省界造成视觉拥挤。
- 地图数据源编码不能直接作为产品的国家分组。台湾、香港、澳门统一归入中国并转换为省级区域；通过真实坐标校验国家归属与省级层次。
- 省界、分省着色和省级拾取必须同时限制在当前聚焦国家内；缩放进入细节时不能展开全球省界。
- 用户要求卡通或手绘风时，字体、地球材质、轮廓、按钮与旅伴插画需统一风格，不能只增加少量装饰。
- 手绘插画不能只给精致卡通造型叠加纹理；需使用松弛不规则的铅笔线、简化五官与扁平色块，让缩小后的角色也能看出手绘笔触。
- 可交互的角色必须使用各自独立的透明素材；拖动坐标与待机动画分层，只在角色按钮内捕获手势，避免影响地球操作。近距离互动在松手后触发，并允许再次拖开。
- 支持省州近景缩放的地图不能依赖低分辨率全球贴图绘制陆地和边界；填色使用矢量多边形，国界采用固定屏幕像素线宽，纸纹单独叠加，避免放大后像素化和边线膨胀。
- 统一手绘风格时也要覆盖默认、可点击、按下、可拖动和拖动中的鼠标状态；光标需设置准确热点和系统回退，并处理三维画布内联样式的覆盖。
- 大型静态地图应在预处理阶段生成共享顶点的矢量几何，运行时只读取资源并根据媒体数据着色；地图数据和三维模块并行加载，重进页面组件时复用解析缓存，避免主线程重复生成全球陆地。
- react-globe.gl 的无贴图就绪回调可能早于 React ref 绑定；初始化必须在挂载后补做且保持幂等。数据和构建通过不代表三维生命周期正常，需确认实际页面的加载提示消失且陆地可见。
- 本项目 GitHub 仓库按用户最新要求设为公有；素材整理与部署说明需明确公开展示副本和仓库外私人原片的放置位置，不能把创建仓库等同于获准提交、推送全部本地文件。
